# 🎮 Hangman Game in Python

A simple yet interactive **text-based Hangman Game** built using Python. The player must guess a hidden word one letter at a time before running out of attempts. This project is beginner-friendly and demonstrates the use of fundamental Python programming concepts.

## 📌 Project Overview

The Hangman Game randomly selects a word from a predefined list. The player guesses one letter at a time. Correct guesses reveal the letters in the word, while incorrect guesses reduce the number of remaining attempts. The game ends when the player guesses the entire word or exhausts all six incorrect guesses.

## ✨ Features

- 🎯 Random word selection
- 🔤 Guess one letter at a time
- ✅ Input validation
- ⚠️ Detects duplicate guesses
- 📋 Displays guessed letters
- ❤️ 6 incorrect attempts allowed
- 🎨 ASCII Hangman drawing
- 🔄 Play Again option
- 🖥️ Simple console-based interface

## 🛠️ Technologies Used

- Python 3
- Random Module
- Lists
- Strings
- Functions
- Loops
- Conditional Statements

## 🎮 How to Play

1. The game randomly selects a word.
2. Guess one letter at a time.
3. If your guess is correct, the letter appears in the word.
4. If your guess is incorrect, one attempt is lost.
5. You have a maximum of **6 incorrect guesses**.
6. Guess the complete word before your attempts run out.
7. After the game ends, you can choose to play again.
